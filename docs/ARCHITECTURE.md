# 公开架构说明

此文仅介绍代码结构，不含内部会议、真实客户场景或企业知识库内容。

```text
Vue 侧边栏 / 审核台 / 管理台
                  |
FastAPI Controller -> Service -> Repository -> MySQL
                           \-> Integration -> 企业微信 / 模型 / 只读 MCP

独立消息同步进程 -> SDK 子进程 -> 标准化 -> 整页事务 -> 全局游标
独立轻量检索进程 <- 已发布 Skill 的可重建派生索引
```

## 关键边界

1. Controller 负责参数与身份边界，Service 编排业务，Repository 负责数据库，Integration 屏蔽平台字段。
2. 会话存档 SDK 只能运行在独立子进程中；单页消息路由和持久化成功后推进全局游标，失败回滚整页。
3. 结构化意图识别在回复前执行，型号未确认时先澄清；产品事实必须有授权资料依据。
4. 摘要与 Skill 候选绑定来源消息；候选必须人工审核才可发布，审核事件及版本冲突可追溯。
5. 管理员负责聊天查看、导出及用户管理；reviewer 不因有知识审核权限而获得全部聊天导出权限。
6. AI 不自动发送；前端采纳只复制草稿，不调用发送接口；客服自行粘贴并确认发送。
7. MySQL 为事实源；向量服务为可选派生索引，故障时回退全文检索，公开默认关闭。
8. 会话连接只查询已有授权：浏览器提交的群 ID/客户 ID 不能建立成员关系；成员必须由可信归档/资料同步建立。未知会话或非成员均拒绝访问。
9. OAuth 不能重新启用已禁用账号；首次改密状态在后端阻止敏感接口访问。公开演示不能复用已有登录令牌访问真实消息。

## 当前验证边界

离线测试使用合成消息和内存替身；前端演示不访问真实数据库。
这些验证不等同于真实企业微信端到端验收，不证明生产性能、回答正确率或业务收益。
`docs/PRIVACY.md` 记录部署者仍需处理的数据授权、存储期限及模型外发边界。
